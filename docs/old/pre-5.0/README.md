# Pre-5.0 Documentation Archive

These files were removed from the live documentation root when the
ABIogenesis 5.0 documentation line was established.

They describe historical 3.x and 4.x Product cuts, the lowered execution
handoff, controller-era public APIs, plugin and hook surfaces, retired
downstream examples, or exploratory strategy. Their bytes are retained for
lineage and comparison. They are not implementation or documentation authority
for ABIogenesis 5.0.

The immutable ABIogenesis 4.6 support line remains the deciding source for
released 4.6 Product history.
