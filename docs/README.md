# Abiogenesis Docs

Live supporting project documentation lives here.

Use this root for explanatory, operational, or supporting material that is not itself the constitutional requirement surface.

The constitutional source remains `specification/`. These docs are operator and
builder guidance over that source.

The current TypeScript release line is `@abiogenesis/typescript-tenant`
`4.5.0-rc.14`. For GTL contract-law/API reload, start from
[`REQ-L-GTL3-CONTRACT-LAW-API.md`](../specification/requirements/gtl/REQ-L-GTL3-CONTRACT-LAW-API.md).

The current 4.1 line includes the downstream-consumable requirements route:
GTL publishes requirement declaration and lifecycle-composition surfaces,
ABG publishes read-only `abg.requirements` query facades, and ABG keeps
declaration admission, evidence binding, fold, residual, and lifecycle
disposition emission inside the runtime path.

## Live Guides

- [USER_GUIDE.md](./USER_GUIDE.md) is the single human guide. It combines
  operator orientation, builder workflow, and technical GTL/ABG reference
  material.
- [LLM_GTL_APP_BUILDER_GUIDE.md](./LLM_GTL_APP_BUILDER_GUIDE.md) is the
  compressed technical guide for LLM agents. It carries the axioms, operating
  constraints, TypeScript-primary package guidance, and the GTL hook/ABG plugin
  setup needed for agent bootstrap.

Both live guides include the current ontology/epistemology boundary: GTL names
the authored carriers, ABG owns admitted runtime truth, and `C` is selected
`abg.fn_composition` notation rather than a new public carrier.
