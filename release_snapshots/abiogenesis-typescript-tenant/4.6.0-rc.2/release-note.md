# abiogenesis 4.6.0-rc.2 Release Candidate Note

It follows `4.5.1` and opens the 4.6 line: the consciousness wave
(T-217) — the supervisor seat becomes a witnessed framework actor, the
operator gains one typed command grammar, closure consumes workspace
truth, and the observer/tuner tiers ship as declared products with
their deterministic halves proven. rc.1 of this line was cut from a
tree with a red constitutional-drift gate and a red lint gate; it is
superseded unshipped, and rc.2 is the first lawful cut of the line.

## The witness family (Phase 1, WITNESS-001..-015)

- Every operator act is a typed, actor-attributed, admitted event:
  declaration reprice, run resume/stop lifecycle, workspace hygiene
  stamps, defect intake, replay-log attestation. Self-certified refs
  throughout — admission recomputes content-derived identities, so a
  forged or partially-mutated ref is inadmissible.
- Substrate drift halts resumes fail-closed BEFORE any drifted truth is
  emitted; coverage is the exact (declarationRef, beforeDigest,
  afterDigest) pair. Basis forks (policy/binding identity changing
  mid-spine) block the same way.
- Replay-log attestation chains a digest over FULL canonical event
  content: tampering inside an attested span is evident on
  re-derivation, cross-process.
- Citability is a replay predicate — converged AND frozen-law AND
  hygiene-clean — with failing conjuncts exposed.

## The operator grammar and the session allowlist (Phase 2)

- The CLI is the grammar's reference adapter: `witness <act>`,
  `observe report|drafts`, `tune report|propose|ratify|reject` — every
  verb reconstructs the run spine from the persisted log and appends
  admitted events through a LIVE emitter context (forged pre-stamped
  envelopes fail closed at append).
- `start --allow` realizes the session allowlist: a narrowing-only view
  restriction over the binding-declared catalog, judged by the
  registry's own enablement law; widening and phantom refs are typed
  rejections. Codex transport steering (`--codex-model`,
  `--codex-sandbox`) is promoted from ambient env to declared start
  arguments.
- Closure consumes workspace truth: a minted "close" over
  foreign-written evidence demotes to block at BOTH closure sites (the
  per-vector fold and the terminal assurance gate) until re-measured
  clean.
- Kernel-witnessed digests (T-209 D1.4): `witness hygiene-stamp
  --measure workspace` reads bytes itself under the canonical
  file-digest law, copies out divergent evidence before stamping it
  foreign, refuses paths escaping the workspace root, and fails closed
  on non-absence read errors.
- The T-216 D3 eviction lands kernel-side: `verifyJUnitReportContents`
  — element-scoped, total, CDATA/comment-inert JUnit verification; the
  odd_glc regex summer dies at its next substrate adoption.
- EVENTS-025 realized: every event kind either carries basis scope or
  is DECLARED run-independent with a named scope class; undeclared
  no-scope kinds fail closed instead of blending across runs.
  EVENTS-026 realized: `payload_rejected` carries structured issue rows
  (absence = the pre-realization persisted shape, kept admissible so
  attested spans stay readable).
- Store-scoped emitter contexts (C-4): the admission ordinal is a
  per-store handle with a live/replay-tolerant flag, threaded through
  all operator routes.

## The tuner tier (Phase 4, TUNER-001..-014)
