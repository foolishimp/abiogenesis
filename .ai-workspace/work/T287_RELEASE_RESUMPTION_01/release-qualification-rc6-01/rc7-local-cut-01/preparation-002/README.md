## Reuse and narrow adaptations

- `run-local-cut.mjs` applies the existing RC6 prepare-source, build-source,
  freeze-cut, prepare-install and close-local-cut sequence with concrete RC7
  paths and actual future pins. It calls the unchanged frozen maintained
  `commandRecorder` / `exclusiveRecord`; there is no copied spawn, timeout or
  capture implementation. Setup, compile, generation, pack, clean reconstruction,
  installation and fresh content check have distinct command receipts/timings.
- `install-local-rc7.mjs` is the accepted RC6 installer with only RC7 identity and
  the explicit input-manifest path/digest interface adapted. The exact diff is
  retained in `INSTALLER_ADAPTATION.diff`. Product verification/lock/install and
  all-member byte-comparison algorithms are unchanged.
- `artifact-identity-bridge.py` retains the existing safe tar/member comparison.
  It uses the actual member population; it does not assume RC6's 5,325 members or
  six changed files. Compiled differences must be the old/new identity byte
  substitution; existing generated projections are listed for packaging review.
  Missing matched native archive requires an explicit pinned Root limitation;
  no native artifact equality is then claimed. Unexpected member or substantive
  byte changes stop for Root.
- Old RC6 writes to M's GOALS, ticket and STATUS, evidence-body duplication,
  native narrative/history acquisition and live C source copying are omitted.
  Main/C HEAD and index fingerprints are checked before/after each future phase;
  only the new worktree index is staged/committed. No push/tag/merge, shared
  selector, immutable-release mutation, automatic cleanup or retry exists.

The current node/npm/tar pins still match the accepted RC6 workflow; git/cp/python
and the four unchanged recorder modules are also pinned. The existing offline
