**Current bug closure must be meaningful.** Deterministic controlled-clock tests must prove acknowledged activity renews inactivity, false acknowledgement does not, absolute deadline never renews, and cutoff excludes later semantic bytes. Physical tests must establish body entry/handler/timer readiness, actual emitted bytes and capture, then direct exit, close, disposal and independent group absence. Spawn callback is not body entry. A negative post-exit case needs demonstrated late emission capability, not a descendant killed before its timer fires. If physical startup budgets change, retain deterministic original clock laws and extend the positive workload so it spans multiple inactivity leases; raising a 120ms lease above a 240ms workload alone destroys the renewal proof. Retain original failures and diagnostic covariates. Focused repaired cases precede the unchanged remainder of the whole m5 file and original unit population; later green does not rewrite earlier red or automatically qualify 5.0.

**Library choices grounded in exact Effect3.22.1.** `Scope/acquireRelease` and scoped fibers suit listener/handle/heartbeat lifetime; `Deferred` suits terminal handoff; `Ref` can hold immutable physical/observer snapshots. None owns ABG state. `acquireRelease` acquisition/release are uninterruptible ([source](/private/tmp/abg-rc11-foundation-20261110-01/build_tenants/abiogenesis/typescript/node_modules/effect/src/Effect.ts:10295)), and `raceFirst` waits for the losing effect to terminate (18932). Finalizers must perform the owner's finite cleanup protocol and publish absence/unknown facts; they must not await arbitrary unresolved I/O indefinitely. Do not use `disconnect` to conceal live cleanup. An interrupted `tryPromise` wait or AbortSignal is not proof that OS I/O stopped. Keep inert Node error guards through natural close so late destroy errors do not become unhandled or rewrite the outcome.

Retain [createMonotonicDeadline](/private/tmp/abg-rc11-foundation-20261110-01/build_tenants/abiogenesis/typescript/code/src/shared/owned_process_lifetime.ts:29) numeric law: bigint nanoseconds, positive-fraction ceiling, finite huge deadlines chunked at the host maximum, stale-arm rejection and absolute non-renewal. Effect's [scheduler](/private/tmp/abg-rc11-foundation-20261110-01/build_tenants/abiogenesis/typescript/node_modules/effect/src/internal/clock.ts:18) treats durations above `2^31-1`ms as infinite; `currentTimeMillis` uses Date.now. A narrow monotonic clock/wait adapter may use Effect for suspension/cancellation while preserving these laws. Do not mix epochs or rebase owner deadlines. TestClock controls Effect sleeps, not child processes or Node I/O; retain exact host-falsifier tests for the adapter and use TestClock only with an explicit aligned clock service for pure/component scheduling.

`Queue.bounded` suspends an Effect producer at capacity ([source](/private/tmp/abg-rc11-foundation-20261110-01/build_tenants/abiogenesis/typescript/node_modules/effect/src/Queue.ts:424)); it cannot backpressure a Node EventEmitter callback by itself. `Stream.asyncPush` defaults unbounded and its finite strategies drop/slide ([source](/private/tmp/abg-rc11-foundation-20261110-01/build_tenants/abiogenesis/typescript/node_modules/effect/src/Stream.ts:488)), which cannot replace lossless stdout capture. If a stream conversion is later justified, bind Node pause/resume or pull consumption to a finite byte/chunk budget, preserve capture timestamps independently of dequeue time, and define overflow/refusal without dropping admitted evidence. Never fork an unbounded fiber per chunk. Cancellation must shut down pending offers/takes and detach input. Keep the current synchronous archive durability path until equivalent admission ordering and actual memory/latency evidence justify change.

**Proof, risk and economics.** Before each production phase freeze the unchanged owner contract, exact observable trace and failure algebra. Replay existing controlled permutations: no-child launch, callback/stdio/disposal faults, first-error preservation, TERM→KILL strengthening, absent/present/unknown group, close-without-exit, Windows direct-child scope, escaped descendants, fractional/huge deadlines and final snapshot immutability. Then execute finite physical command/HTTP/worker witnesses with records retained before cleanup, plus archive fsync/rollback/corruption and current-profile ABG admission/replay checks for phase4. HTTP's existing pre-await-only `observing()` checks expose a concrete late-read/response falsifier to assess before changing behavior; this is not attribution of the historical failures.

Implementation cost rises from small observer/test changes to medium shared lifetime/command and HTTP changes, then high-risk worker capture integration. Shared lifetime/caller edits are sequential, not parallel. Independent oracle/design preparation may overlap; source freeze and finite physical proofs must be serialized. Admit each later phase only if it deletes named manual state/listener/timer/finalization machinery and preserves the observable relation. Record deletion, branch/state complexity and retained adapter cost; do not promise speed or memory gains without later matched measurement. Rational no-change choices: retain the proven deadline arithmetic, process-group probing/signalling, domain classification, expected-prefix/event calculus, schema/library pin and currently correct archive laws. No blanket production rewrite, Effect upgrade, RxJS migration, generic scheduler or expanded runtime authority is selected by this plan.
