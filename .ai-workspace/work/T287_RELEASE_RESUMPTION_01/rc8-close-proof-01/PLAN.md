   There is no repair or automatic retry. Tests' existing hooks own their own

explicit larger per-file limits for existing 9–30 minute cases and the multi-case

no claim of an aggregate RSS bound. Only one test file is active at a time.

socket headroom. npm is offline and reuses staged dependencies.

retained output approaches the bound, stop with custody and return for disposition;
