# Current amendment baseline rubric

Review: baseline

This review judges the adequacy of current evidence and analysis. It does not
judge application acceptance. A failing application probe can be adequate
evidence of the change that remains to be implemented. No stage count, author
assertion or host observation substitutes for an admitted Testing producer.

- B1: The full authenticated, current Testing producer includes both declared commands, their exit statuses and streams, and their process-exit predicates. The protected oracle reports all four declared cases with actual total and managerApproval values. Absent, refused, truncated or foreign evidence is indeterminate; do not infer it from prose.
- B2: The actual intake and impact documents classify and trace this requirement amendment, identify the affected/shared/preserved surfaces and propose a coherent bounded realization and test change. Read these exact documents and sources.
- B3: Explain every actual mismatch or absence of mismatch between the current application and amended examples, using the current realization and authenticated oracle output. Relate that evidence to the retained impact plan and what remains or has been completed. Before construction, unmet amendment behavior is expected evidence; it is not a reason by itself to mark this evidence review unmet.
- B4: Preserve the independent acceptance and preservation criteria. A satisfied baseline means adequate evidence and applicable analysis only. It neither accepts the application nor chooses the next graph. Changed current dependencies require this review to be evaluated afresh.
