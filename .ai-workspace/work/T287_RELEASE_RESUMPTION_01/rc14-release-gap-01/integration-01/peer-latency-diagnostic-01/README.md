argv, bounded call stack, launch/exit/close times, exit code, signal, killed,

digest covers every observed data chunk; truncated raw capture is named.

constructed Error) are not reconstructed; actual child termination and output
remain observable. Synchronous child_process calls are not covered by Node's
channel. There are no Product imports or private owner substitutes.
