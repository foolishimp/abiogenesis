# Proof/Install preparation

Product frame: GOAL-035/T-287 selects the common computational library as a prerequisite to the fixed fifteen-family ABIogenesis 5.0 Product. This Writer prepares L3 proof glue under the accepted L2 contract. GTL declares; Product and implementation owners perform their declared effects; ABG admits runtime truth; Event Calculus and replay project it. The runner and oracle are observation/evaluation support, with no admission, currentness, acceptance or release authority. L4 and L5 are not activated by this preparation.

The compact path design is reused from [accepted L2 Proof/Install](../../proof/L2-report.md#finite-installed-paths-and-independent-oracles), its [execution contract overrides](../../L2-execution-contract.md#6-finite-proof-contract-and-ordering), and the accepted common library's [native sequence](../../../../../build_tenants/abiogenesis/typescript/design/ABI5_COMMON_COMPUTATIONAL_CAPABILITY_LIBRARY_DESIGN.md#sequence-view-prepared-native-work) and physical-resource state view. No new execution framework or runtime schema is introduced.

`proof/run-installed.mjs` implements exactly `public-preparation`, `partial-install`, `declared-execution`, and `stdo3-native-selection`. It consumes selected-stage support and installed package owners. The source-helper closure has 12 baseline files and 13 candidate files; only the candidate adds the standalone source factory. The historical companion helper is absent from that closure. The native fixture's package import resolves through the selected staged package during declaration preparation and through the independently packaged fixture's installed dependency during execution. Its source never supplies runtime admission.

The runner checks the final configuration, effect grant, runner/oracle pins, exact toolchain, stage/source/generated/dependency inventories, archive, support and package inventory before runtime effects. Configuration templates deliberately fail this check. No configuration is admitted here and no candidate stage is selected while peer Writers remain active.

For later activation, the Executive fills a new configuration from `configuration.template.json`, preserving exact mode names and fixed P4 task/provider/timings, then writes a separate new `effect-grant.template.json` successor binding the configuration's byte hash and the actual frozen runner/oracle hashes. Grant resources equal the selected lane's configured roots. Each root is initially absent, disjoint from the stage and historical resources. The configuration's inventory entries use `files:[{path,sha256,bytes,mode?}]` (symlinks use `type:symlink,target`) and an explicit absolute verification root. These are local proof input lists, not Product carriers.

The baseline already built and packed. `baseline-configuration-inputs.json` and `baseline-package-inventory.json` bind its existing archive and 5,267 file members; reuse them without rebuilding the baseline. The candidate must be made only from the closed source freezes plus the preserved baseline inventory, then built/generated/packed in its separate stage under the later grant. A full generated/dependency inventory must bind the stage's current emitted modules and independent locked dependencies. Both support manifests must match their respective selected stages. No mutable-main dependency link or network fallback is permitted.

Execution uses the accepted command form, for example:

```sh
node "$ABG_PROOF/run-installed.mjs" --configuration "$ABG_L4_CONFIG" --lane public-preparation
```

The frozen task/oracle is independent of implementation output. `oracle.mjs` does not fold raw events into runtime truth; predicates receive owner receipts and projections. Event inspection locates actual process/selection/call evidence and verifies declared population counts. It cannot infer admission or currentness. P4's single semantic result does not establish general STDO application quality, user acceptance of ABIogenesis, all workloads or release qualification.

`coverage.json` keeps every P1–P5/V1–V7 obligation open until exact evidence is conjoined. Local source tests, controlled owner histories, actual physical processes and installed paths remain separate. `comparison.json` fixes output correspondence before observation. `measurement.md` states the uninstrumented witness, diagnostic needs and unobserved quantities. `retirement.json` fixes the two-sided finite source/emission/package/assurance check and separate disposable mutation rule. No whole-suite gate is added.

Stop on the first failed prerequisite or seam, basis drift, unsupported owner/interface change, missing required actor or unknown physical completion. Preserve `failure.json`, retained directories, available requests/receipts, event bytes and actual handoffs; return to Executive. A failed helper may have produced files before returning a value: its configured scratch parent and child inventory remain evidence, not cleanup permission. No L4 result exists in this preparation.
