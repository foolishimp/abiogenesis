The immutable correspondence is in `comparison.json`. Baseline and candidate P1/P3 use the same authored workload, recursion bound 3, Node 24.7.0/npm 11.5.1/TypeScript 5.9.2, offline lock and measurement regime, with distinct new resource roots. The runner is the uninstrumented endpoint witness. It records monotonic wall intervals for bootstrap installation, first installed-owner acquisition, Public preparation, first/warm resolution, P3 aggregate setup/start, each fresh CLI read and the native interval. It records parent `process.cpuUsage`, before/after `process.memoryUsage` samples and `process.resourceUsage`; resource maximum RSS uses Node's documented KiB unit. The P3 helper's returned `execution.wallMs` separates its start CLI interval from aggregate preparation but does not reveal internal phase attribution. Add the exact returned interval to the later measurement analysis, without subtracting overlapping samples as if they were independent CPU totals.

For complete-process observations, run each admitted command under the host's existing `/usr/bin/time -l`, preserving its raw stderr separately from CLI stdout. Capture wrapper identity, argv, cwd, start/end and return code. Label whether a maximum is for the runner, the wrapper's child population, or an individual CLI/native child. Do not sum unrelated maxima, present sampled heap as a peak, or infer allocation causes. The actual platform and `/usr/bin/time` output unit must accompany the number.

Record archive bytes, package-member bytes, prompt/request/event/output bytes, and final retained logical/allocated footprint by root. `du -sk` reports KiB and copy-on-write allocation may overlap. Include source mirrors, generated fixture packages, bootstrap and two Product installation roots, scratch, dependency preparation and evidence. The measurements file and final result add their own bytes after the initial snapshot; final footprint must be acquired by the later measurement observer after the lane closes. Report retention and preparation costs even if runtime work falls.

Freeze the observer and scope before the diagnostic run; do not alter returned bytes, equality, cache/currentness law, timing bounds, environment identity or provider semantics.
