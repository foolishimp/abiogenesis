# Bounded successor transport for the unfinished review checkpoint

This extends the closed portability02/successor04 repository/package/object
relations. It is transport and custody proof only: no Product execution,
re-admission, cleanup, executable-environment reconstruction or delivery acceptance.

The activation enumerates 24 exact freezes, four original physical inventory
carriers, two closing addenda and two exact original packages. Native fields and
their declared bases select every row; no directory walk discovers original
runtime bytes. The previous carrier remains immutable. Its exact hash/package
routes are reused where they satisfy a selected identity; only unmapped required
bytes become new inert objects. Visible repository stage/source copies are
included by the full-tree checkpoint and may also satisfy exact byte routes.

Frozen original rows retain path, hash, size and original metadata separately
from normalized transport identity. Directories/symlink targets remain original
observations. Exact V8 cache rows and the pinned system Node executable are
metadata-only exclusions. No ambient cache, provider binary, credentials, private
session reasoning or continuation17 path is selected. Runtime copies are never
opened as a receiving-machine fallback or treated as current stores.

The existing package-member algorithm verifies the two raw original archives,
including their member names/bytes/modes. Installed bin-mode normalization remains
the original recorded relation. Existing package/member and repository routes
are preserved. New unique objects use the prior 64 MiB payload chunks and inert
`objects/sha256/<digest>` members, giving archives below 90 MiB. The local new
payload plus records is bounded to 2 GiB and new compressed archives to 1 GiB;
these are transport bounds, not runtime workload or performance claims.

The predecessor packager's regular-file gzip/tar construction and byte checks
are reused. Its old population/physical-root assumptions are replaced by these
explicit selected subjects and retained source states for only newly copied
objects. Verification reads repository files and inert archives without
extraction, verifies each selected row's finite coverage relation, and has no
original absolute-path fallback. A first actual mismatch stops for Root before
repair or retry; the stopped records remain.

Review portability includes source/package identity, actual retained request,
response, journal/prefix, failure and measurement evidence within the selected
cuts. It does not recreate installed paths, process identities, task caches,
provider executables, symlink authority or a runnable historical environment.
Original failed cuts remain failed. Independent current source/HOW review,
execution, L5 and release claims remain separate.
