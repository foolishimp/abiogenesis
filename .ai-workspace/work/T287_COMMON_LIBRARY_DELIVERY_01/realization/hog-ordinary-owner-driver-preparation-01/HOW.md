The direct `setupInstalledRootExecutionBasis` helper requires a root C.of leaf.
Workflow and fan-out roots do not meet that premise. The driver instead uses
`setupInstalledRootCatalog`, `constructInstalledStartCall`, the installed CLI,
and `constructInstalledRunReadCall`. These are existing ordinary owner seams.
Its transport wrapper writes the same declared JSONL request and retains raw
stdout/stderr/exit; the existing convenience wrapper omits those process fields.
No invocation, admission, traversal, retry, or projection algorithm is copied.

Each case has a fresh host, scratch parent, evidence directory and cache. The
setup helper's actual workspace remains beneath its generated scratch directory;
the proposed worksite path is reserved but not substituted for that owner path.
Npm uses an explicitly inventoried cache seed copied into that case's new cache,
with offline/no-script environment. Its cache and log effects are retained.
The explicit frozen-artifact argument prevents ABI rebuild or fallback pack.
The structural fixture consumes that exact archive through its repaired physical
dependency handoff; default declaration/leaf bytes and sourceTransform absence
are mandatory. Its own pack/install is a later effect, not performed here.

The independent oracle is fixed in oracle.mjs before any workload observation.
Compose/retry: whitespace input normalizes to literal `World`, one successful
declared retry attempt has completed progress consumed by an actual projected
route. Workflow: one atomic child closes and its exact admitted foldback joins
the parent result. Fan-out: ordinals 0/1/2 respectively complete/block/remain
unstarted; no reducer, complete vector or success Run closure. This last path
expects blocked Run truth and fresh replay, not a successful Result read.
Actual owner projectors authenticate historical route, foldback and fan-out
carriers at their event cuts; the oracle joins those outputs and event references
without recreating owner digests or authority.

Setup after-hooks are captured and never called. Start/fresh reads consume the
actual returned close handoff each time. The oracle checks the read's returned
prefix and raw bytes against that actual input; equality is a measured condition,
never a substitute authority. A refusal, process signal, malformed output, or
failed predicate retains requests, output and all physical roots and stops all
following cases. Failure recording never reopens, closes, retries or cleans an
unknown owner state. No native dispatch is permitted by the selected F_D closure.

The driver preflight authenticates all pinned inputs before imports/effects,
verifies exact installed package members before owner loading, rejects historical
final01 as an execution subject, and requires a separate configuration/grant.
The NOT_GRANTED template cannot run. Future binding must translate final
inventory carriers explicitly; it must not refresh mismatched source hashes.
