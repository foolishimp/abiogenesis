# ABG-owned sandbox UAT inputs

These seven cases are test inputs and independent acceptance oracles outside
the Product package. `scenarios.json` is the local selection manifest. Every
manifest path is relative to this directory. No runtime read, import, resolver,
toolchain or installation depends on the donor checkout.

Each `source.original.txt` preserves the exact selected donor declaration
bytes. `obligations.json` projects its data literals without copying the donor
runner. The six Hello oracles retain their original bytes. Data Mapper also
retains the exact supporting constants and the independent observable-contract
JSON slice. Its complete primary oracle preserves all source obligations;
the smaller observable contract cannot replace it.

`request.json` is a test-owned template for the current generic governance
input. `sourceMembers` binds local files to protected worksite paths and
digests. The harness supplies the installed assessment contract/schema and
exact executable capabilities before the canonical owner constructs the input.
All six ordinary governance purposes remain available. No application source,
test implementation or claimed execution result is supplied as a solution.

`legacyInterpretation` makes representation changes explicit. Old donor
wrappers, graph/type references, startup/vector language and witness paths are
historical meaning or provenance. Current native traversal does not establish
identical old traversal. Original application, lifecycle, correction, depth,
mutation and archive outcomes remain mandatory; unresolved interpretation or
missing evidence keeps the UAT outcome non-green.

Data Mapper's exact source has 28 stage meanings. One retained instruction
still says 26; the extra earned-depth and mutation obligations are preserved.
Its eight concerns require all five depth classes tied to actually executed
ScalaTest identities and genuine compiled mutation kills with exact restoration.
Scala/SBT, actual Spark SQL, the eight original reports, at least 20 real passes,
the original build contract and the declared offline/JDK/socket obligations
remain selected. Integer addition, lite mapping and collection-only substitutes
do not satisfy this case. The Rust service remains the original standard-library
`src/service.rs`/`rustc` case, rather than the later Cargo-crate compression.

`independent-oracle.mjs` exports `evaluate({worksiteRoot, runArchive, commands,
events, source, request, observationOwner, validateObservation})`. The harness
supplies exact installed C2 GraphFunction/output contract/success/Run coordinates
and `validateObservation` through the published installed C2 judgment relation.
Only that producer's direct owner-validated output supplies canonical task and
command rows. The resolved original executable/argv/cwd/limits/reports and
explicit environment values must agree; actual commands must retain the complete
owner-bound environment. The original-to-task native preparation owner retains
PATH prefix normalization. No private owner import or copied normalizer is used.
Missing owner support remains indeterminate. Its test-owned mechanical checks
consume those exact observations and retained report bytes.
Worker-authored report or mutation metadata cannot manufacture command evidence.
Missing authentic mutation episodes produce `indeterminate`. The caller also
requires independent native semantic UAT, exact installed admission and fresh
Public result/replay closure. Mechanical readiness is not live UAT or release
qualification.

`acquisition.json` records donor commit, byte ranges, whole-file digests and
selected digests. Donor addresses are provenance labels only; all selected
input/oracle bytes are local.
