# Mechanical proof limits

The component proof requires an actual native Construction observation, an
actual C2 exit-1 diagnostic, a native repair confined to fixture/value.txt, an
actual remeasurement with exit 0, and conservation across close/restart and
fresh owner reads. The failed and passing command ids and checker bytes must
remain identical. Each measurement keeps its own producer and current inputs.

These observations do not establish independent UAT, Claude behavior,
Data Mapper correctness, large-history capacity, or release qualification.
An explicit selector gap leaves the original support obligation unresolved.
