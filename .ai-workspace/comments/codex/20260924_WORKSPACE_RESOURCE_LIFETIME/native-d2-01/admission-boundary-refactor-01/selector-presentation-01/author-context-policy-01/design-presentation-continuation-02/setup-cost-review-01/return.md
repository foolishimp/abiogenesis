## Ranked current correction

**1. Preserve the existing artifact derivation at the immediate install-owner handoff.** This is the concrete same-process proof-loss defect. After successful append, `environment_admission.js:560` returns `projectValidatedPrefixArtifactTruth(...)`. That function constructs/hashes the entire successor projection but returns a plain value (`artifact_truth.js:366–406`). It does not attach the existing `ArtifactTruthDerivation` or register `exactProjections`.

The immediately following `install_definition_bindings.js:177` calls `projectAdmittedProductInstall`. Its selector invokes `validateArtifactTruthProjectionValue` (`environment_admission.js:32–35,297–306`). Because the actual internal result lacks the derivation, the raw fallback runs `projectExactPrefixArtifactTruth`, creates/hashes the same successor projection again and canonical-compares both full bodies (`artifact_truth.js:434–465,481–501`). The consumer needs one admitted install row; it receives roughly 74.21 MB of complete artifact history and retraverses it. This work scales with accumulated artifact history, not the one install being acknowledged.

Smallest patch territory: the existing ABG artifact-admission return/owned projection composition. Return the existing authenticated projection factory's result for `appended.successorPrefix` (with its existing typed-refusal handling), retaining that exact object into the current consumer. Reuse the existing `ArtifactTruthDerivation` and `exactProjections`; do not add a cache, registry, Public token or second state owner. This removes the avoidable second construction/hash and full-body equality while preserving the serialized projection/digest, new candidate validation, append/rollback, currentness and raw/copied/cold reconstruction. It is distinct from changing the large Public projection representation: that larger decision is not needed for this patch.

**2. Secondary bounded contraction:** after the install boundary establishes the exact immutable lock/candidate relation, carry those established facts through this same owner call instead of repeatedly invoking the complete raw lock predicate. Keep candidate-specific membership, scope, exact prefix and effect checks. This is a source-supported repetition opportunity, not evidence that it dominates elapsed time and not an additional prerequisite selected by this audit.

Focused falsifier for the first patch: the existing real append → install projection case must return an owner-derived successor that directly projects the same admitted install and identical serialized projection/digest; the immediate consumer must perform no second whole-projection construction/equality. The corresponding serialized/raw copy must still take raw validation, and existing refused-candidate/cold-recovery outcomes must remain unchanged. Reuse the existing owner test rather than starting a new suite.

Minimal timing discriminator, only if Root selects measurement during a later already-required install: retain three local elapsed spans around `ProductInstallPort.install`, `admitProductInstall`, and `projectAdmittedProductInstall`. This separates physical materialization, admission/history work and the immediate redundant consumer. The wrapper residual remains explicit.
