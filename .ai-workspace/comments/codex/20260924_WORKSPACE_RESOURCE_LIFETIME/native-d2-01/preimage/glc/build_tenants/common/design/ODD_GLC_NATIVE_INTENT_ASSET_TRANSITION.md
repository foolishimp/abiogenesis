## Source, construction and structural evidence

The input basis lists every selected source member with canonical locator, role and exact hash. The worksite exposes its complete bytes, the basis and the full declared Intent policy. The author must read all selected source bodies, conserve outcomes/users/constraints/uncertainties, preserve modality and conflicts, quote the actual source and retain pending obligations. The external pure F_D evaluator checks the unchanged source/policy basis, correct observed input bytes, a present UTF-8 Markdown Intent asset, required headings and literal selected-source identities. Its `satisfied` means **structural readiness with independent semantic assessment pending**. These checks intentionally do not infer source completeness or quality from headings, hashes, counts or quotations. The raw native report remains location/gap evidence. A successful tool exit, observation or structural graph result cannot prove that an Intent faithfully preserves the source. No output file or candidate summary can assert an owner scope ruling.

The next fresh Reviewer receives these exact coordinates and independently reacquires both complete source and actual asset. It receives the applicable RC4 Derived Reviewer and project Product/Proof/Owner frame; required evidence cannot be replaced by this HOW or the author's return.

The Reviewer has no subject write territory. No continuation/session state from the author substitutes for source acquisition. The Reviewer evaluates every policy criterion as satisfied/falsified/indeterminate with source/candidate evidence and returns only to Executive. Any changed source, policy, Intent, native basis or evidence invalidates the affected assessment; unaffected source evidence retains only its prior scope.

Executive may conjoin structural and semantic evidence for this one IntentAsset. An unsatisfied/indeterminate assessment leaves the asset a candidate and routes a newly selected repair to its owner. No automatic retry, semantic advancement, application closure or release disposition is implemented here.
