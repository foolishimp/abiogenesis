## Generator Integrity Finding

Deriving `PublicOperationId` through `keyof` exposed mutable alias state in
`ts-json-schema-generator`. An initial local workaround generated valid JSON
but collapsed `operationContract` to `null`; that output was rejected and was
not checkpointed.

The accepted implementation uses fresh generator segments around the affected
host descriptor. Generated bytes remain stable except that the exact inline
`ProductToolchainManifest` schema moved to a local `$ref`; the referenced
definition was compared with the former inline object and is identical.
