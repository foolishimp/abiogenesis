Publish one ordinary default-library module with seven callable purposes:
recursive Executive, induction, specification, design, construction, testing
and UAT. Construction wraps the existing native coding-worker GraphFunction.
The other work wrappers reuse existing native work/assessment/execution owners.
Their GraphFunctions have distinct declared purposes, contracts and policy
assets; selection invokes a permitted registered wrapper, not a label in a
universal runtime dispatcher. Consumers select/restrict/replace these ordinary
catalogue contributions. There is no required induction→specification→design
sequence, role hierarchy or graph generation.

## Common application contract and coverage

Use one small typed library input/result, `governance_work_state`: original task
and exact selected source identities; declared outcome/criterion and authority
references; applicable installed policy/assets; currently supplied or observed
worksite/evidence coordinates; requested bounded work and retained unresolved
outcomes. These are application data, not a new ABG ledger or obligation engine.
A child returns its bounded product/measurement, source/producer correspondence,
explicit gaps and the conserved parent state. It cannot replace originals,
strengthen its grant, discard valid evidence or certify parent convergence.

The table specifies callable coverage, not mandatory calls. “Ready” below means
the bounded capability result exists; it does not mean the application is done.
All semantic interpretation, suitability and sufficiency judgments are F_P.
F_D performs declared copying, schema/identity checks and total control rules.

## Selected execution relation

The optional recursive Executive performs parent evaluation → owned preparation →
one frame-bound F_P synthesis → F_D choice projection → one exact permitted
wrapper → ordinary child Result/foldback → parent reevaluation. The Program
fixes the registered domain, workflow callees and finite recursion bound. No
ConstructionComposition or mandatory stage sequence is introduced.

The synthesis maps the conserved problem to registered contributions with
interpretation, contribution/reason/support/evidence, relevant dependencies,
explicit gaps, and an explicitly selected next member. Suitability, priority,
dependency interpretation and sufficiency remain F_P judgments. F_D validates
closed reference/contract relations and transports the chosen member; it never
ranks, fills a gap, finds a ready dependency or schedules every listed member.
Every dependency must name another contribution in that same current response;
prior completed work outside the mapping is cited through evidenceRefs. These
cross-field rules are stated in the actual rendered response contract.
Later admitted evidence may lawfully revise the mapping. Catalogue membership
and purpose establish neither semantic suitability nor completion.

The library owns three application contracts. `framed_synthesis_task` carries
current conserved state and bounded actual worksite context. Raw
`framed_synthesis_response` carries the current judgment, next member (or null
with a gap), explicit subject-evidence Result when needed, and revision reason
and evidence. `framed_synthesis_result` conserves that raw judgment and input
state, adding mechanically bound input/task, selected environment/frame evidence,
context and prior synthesis Result coordinates. The strict raw binder is shared
by native completion and Result admission; it preserves observed values without
stripping, repair or model-authored authority echoes.

The template declares `abg.framed_synthesis_locus` and
`abg.framed_synthesis_projection`. The former is the F_P synthesis leaf; its
immediate successor is the fixed F_D projection and existing registered-selection
source. `gtl/stdo_run_environment.ts` recognizes this exact profile under the
explicit Program/run-environment selector role before interpreting payloads.
Invalid applicable bindings refuse; unrelated F_P payloads remain ordinary data.
Assembly uses the existing authenticated occurrence, run-environment source
projection, imported contract callback and admitted definition identities. It
projects only selected frame spans, purposes/contracts/effects, complete original
source and current observations. Catalog readiness bodies are not prompt input.
The existing selector identity projection includes invocationAdmissionRef so
persisted assembly and cold replay join the same admitted environment.
Observed Testing captures command and HTTP launch defaults at preparation only.
Its shared input/task relation conserves every explicit declaration constraint
against the admitted normalized environment; replay never reacquires ambient
HOME, TMPDIR, LANG, LC_ALL or PATH from the reading process.
Actor admission supplies the consumed raw observation to the same binder; there
is no duplicate assembly or history walk at completion.

The projection consumes the actual preceding admitted synthesis Result. It
transports `nextGraphFunctionRef`, reason/evidence and exact declared child
contract into the unchanged `registered_graph_choice` or existing gap primitive.
Normal registered-selection admission and the workflow's fixed-callee/input
checks still own launch. Exact actual source Result identity comes from the
existing cursor input occurrence, never a model response field.

**FS-C01:** current state stores only `{resultRef, resultDigest, basis, judgment}`.
The judgment is the compact raw current response; its basis includes the prior
Result reference. It cannot contain a prior whole Result or input-state body.
The transient bound Result carries its current input state once so the following
projection needs no new retained edge across consumer/library semantics owners.
The projection discards that wrapper. Older complete mappings remain their
ordinary admitted C-call Results. Folded observations identify their synthesis
Result and selected registered GraphFunction, conserving revision attribution
without a second event ledger.

Each work wrapper projects the common state into the existing native/C2 task,
invokes its fixed child, and folds its truthful observation back. **FS-C02:**
`projectTraversalInputAtPrefix` already validates the retained child/result and
foldback relation. Its internal input-origin return retains that same computed
object; the authenticated native basis exposes it to the fold, which consumes
its actual Result and CCall. This adds no serialized proof, cache, event or second
projection. Native, C2 and assessment actor coordinates come from the actual
typed child observation. In particular C2 has no `source.provenance.cCallRef`;
its actual Result aggregate supplies the call coordinate. Root/direct input and
occurrence/prefix validity remain unchanged.

Only the parent applies the declared total verdict rule to an independently
assessed original outcome. A successful measurement of failing behavior folds
truthfully while the parent remains open. Neither reports, stage counts, file
presence nor successful child closure establish the outcome. Unknown required
inputs refuse before launch; original task/authority and unresolved support stay
conserved through every mapping, choice and fold.
