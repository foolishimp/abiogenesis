## One state/event relation, two operations

The proposed EC HOW defines the complete phase table from actual handoff/call,
input origin, Result/Judgment, effect, child/fold, parent, Run and Continuation
facts. Existing admission initiates a selected position or required return;
actual advancement/discharge ends that local remainder. Failure terminates only
its activity. Historic evidence and unmet outcomes persist by their existing
relations; current reliance is a separate dependency/applicability judgment.
Resource reopen reconstructs once. Warm handoffs consume established state.

Totality concerns replay and admissible dispositions, including unknown/block;
it is not an F_D semantic next-action controller. HoG and admitted GTL retain
selection/traversal authority. F_P judges semantic adequacy and suitability where
no total closed rule exists. `eligible/open/stale` coverage is not synonymous
with `satisfied/falsified/indeterminate` semantic judgment.

For **fresh work**, each invocation has its own authority, execution identities,
current observations and ordinary parents/foldback. Reused prior Results retain
their original call/actor/Run identity through exact source-use admission. A new
judgment can establish current outcome satisfaction without retroactively closing
an old failed call. No continuation claim, replacement stack or extra event family
is needed merely because obligation refs recur. Old observations must not be
silently retargeted; historic counterevidence stays historic. The new Run cannot
be used to evade a bound that applies to the selected correction lineage.

For **explicit execution resumption**, the HOW fully states the different
relation: current continue-operation grant versus original work authority;
actual progressed input versus entry input; phase/effect eligibility; consumed
allowances; one-use claim; active versus terminal Run; conditional current waiting
parents and retained evaluator/child-result uses; required parent reevaluation;
duplicate and partial publication. Original Results/Judgments are never copied
into fabricated executions. The EC HOW gives the generic `currentIntent`
reference meaning and necessary existing-family lifecycle additions, conditional
on selecting this operation for implementation. Their published contracts/effects
must be registered before use. They are not selected for normal fresh progress.
