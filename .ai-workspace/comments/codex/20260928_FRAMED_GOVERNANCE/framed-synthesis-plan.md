## One isolated capability and its meaning

Replace the default library's single-answer Executive leaf with one **frame-bound F_P synthesis judgment**, followed by a mechanical projection into the existing single-choice primitive. For the conserved problem, it records an interpretation and a finite selection of registered capabilities, the contribution each is expected to make, reasons/support, relevant dependencies, gaps, and the explicitly selected next member. There is one native judgment per Executive step. No second F_P merely restates that chosen member.

This is ordinary application data inside the existing default-library GraphFunction. `PRODUCT.md:605–712,799–821` already supplies Task/Basis/State, graph composition/frame, admission and reuse law. The Program still owns every callable and fixed workflow target; HoG owns every traversal. Membership proves neither suitability nor sufficiency. The mapping does not change topology, grant effects, create obligations beyond the original task, or require every member to execute. Later evidence may cause F_P to revise it. Parent closure still requires the independently assessed original outcome.

Dependencies describe the F_P judgment's expected reliance between contributions, not an additional executable scheduling language. For example, acceptance may rely on test evidence about the current candidate. The next-member judgment must explain its choice against those dependencies and actual observations. F_D checks reference/shape consistency, never interprets prose, infers satisfaction, walks a dependency frontier or selects a ready member. Required runtime input/currentness/effect prerequisites remain the existing declared child contracts and admission gates. A semantically inconsistent dependency/next judgment remains attributable F_P error; admission does not certify it as sound or silently repair it.

The selected next reference must be one of the contributions. Null next requires an explicit nonempty gap over unresolved original support. Preparation preserves `original` byte-for-byte, original support/authority and the current state. Binding the response copies that state mechanically; the model cannot edit it. The ordinary result deliberately carries this conserved value so the following F_D leaf needs no new retained-input edge in a consumer-owned Executive graph.
