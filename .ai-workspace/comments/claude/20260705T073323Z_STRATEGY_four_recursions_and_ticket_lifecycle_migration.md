## 1. The frame

The system is four distinct recursions sharing one small algebra (typed
carriers + admission + replay + fold), each with its own state, joined only
by reference. None was designed as a grand scheme; the emergence is real
because the algebra is small.

| Recursion | Loop | Its own state | Substrate surface |
| --- | --- | --- | --- |
| Traversal (shop floor) | graph functions calling graph functions; frames, spans, foldback | replay-derived traversal truth per frame | ABG runtime (built; T-188/T-190/T-192 harden it) |
| Factory (production lineage) | source project -> release cut -> install -> builds the next product | admitted provenance/release truth per instance | recursive product taxonomy; partially manual today |
| Homeostatic (intent) | model vs telemetry -> gap -> work -> new telemetry | constitutional model + derived pressure per generation | gen-gaps, executive observer, residual pressure |
| Sampling (disambiguation) | propose -> measure -> re-condition -> repeat | accumulated conditioning per attempt chain | F_P dispatch + admission + retry frontier |

The resolutions below deliberately preserve the separation: no meta-system,
no merged ledgers, reference joins only.

## 2. Intent is a gap, not a document

Intent = the delta between a homeostatic model (the declared set-point:
requirements, proof policies, target contracts) and real-world telemetry
(replay-derived projection, observed-state admission). The runtime already
ratifies this: **"delta is derived truth, not stored authority"** (runtime
truth rule 4). `gen-gaps` and the executive observer (pressure facts feeding
continuation/re-entry/reprice) are the homeostat.

The violation is at the constitutional level: `INTENT.md` is stored prose
pretending to be the signal. A frozen INTENT (last entry 2026-03-25) is a
**dead set-point** — the gap computes against a model nobody maintains, so
operative intent silently becomes whatever the tickets are doing (the
hourglass finding, restated causally).

Two consequences:

1. **Intent is derived per generation, never carried.** Do not serialize
   "intent" into release artifacts as provenance; carry the model and the
   telemetry, recompute the gap at each node.
2. **Constitutional surfaces must become the model half of a live gap
   computation** — convergence-tracked, drift-checked artifacts. INT-002
   proposed exactly this for bootloaders in March 2026, was never realized,
   and its predicted failure then occurred (the stale "workflow program"
   axiom in the installed bootstrap). Generalize INT-002, do not re-derive
   it.

## 3. Bootstrap asymmetry becomes recursive symmetry — and the residues rot

`{human bootstrap} -> C compiler -> gcc 1.0 -> gcc 2.0`: the first arrow is
asymmetric (produced outside the system); afterwards the lineage is
self-similar in information space. The asymmetry never disappears — it
**relocates upward**: after symmetry the human stops producing artifacts and
holds the homeostatic model. The change-class ladder already encodes this:
`goal_reprice`/`intent_reprice` are the human's permanent residence; F_H is
the constitutional form of the bootstrap human. Provenance chains
terminating at a human root are the chain's axiom, not a defect.

**Asymmetric residue inventory** — artifacts still hand-produced that the
factory could produce or check about itself; each is a demonstrated or
predicted rot site:

| Residue | Evidence of rot |
| --- | --- |
| Installed bootstrap (`CLAUDE.md`: "authored and validated here; not generated by ABG") | stale "workflow program" axiom shipped to every downstream agent until caught by review |

Cure per residue: pull it into the symmetric regime — generated from live
truth, or drift-checked against it (the T-187 installed-context conformance
mechanism is the working precedent).

## 4. Instance separation (the state-space point, de-metaphorized)

Each factory instance has its own basis (admitted vocabulary: node types,
carriers, diagnostic IDs, registry entries) and its own state (event
stream). Meaning is basis-relative; a **change of basis requires an explicit
operator** — the installed-context artifact IS that operator, which is why
T-186/T-187 treating it as first-class law was the right investment. Lawful
correlation between instances is only via admitted refs: digest-pinned
provenance is deliberate, explicit correlation; anything ambient is a
defect. The week's failure classes restate crisply: `two_truth` = one state
secretly represented in two spaces; `declared_not_wired` = an operator
declared but never applied; `caller_asserted` = classical injection
bypassing measurement.

**One-line law (to be recorded in T-191):** factory provenance and traversal
lineage are disjoint carrier families joined only by reference — at
admission (factory -> shop: provenance seals when a declaration is
admitted), and at self-hosting output (shop -> factory: a produced program's
provenance cites the producing run).

## 5. Constrained probabilistic traversal (the dynamics, kept narrative)

An unresolved F_P edge A->B is a distribution — INTENT.md's founding claim
("a bounded program-construction space") restated. The topology, contracts,
and rendered manifest are the conditioning; dispatch is a draw; admission
judges whether the draw landed in the admissible set; iteration is
re-conditioning until concentration. Three ratified laws are this model's
hygiene:

1. **Non-tautology = no pre-collapsed preparation** (a prompt carrying the
   answer makes the measurement vacuous).
2. **P0 no-dispatch = don't sample a degenerate distribution** (F_D closes
   deterministic edges).
3. **Re-preparation = the digest-inequality retry guard** (a new attempt
   must change the conditioning; i.i.d. re-rolls are the loop-shaped bug).

Monte Carlo classification, precisely: **rejection sampling with an adaptive
proposal, toward a certificate rather than an estimate** — convergence is
membership in the admissible set, not standard error; and the independence
assumption inverts (samples must be maximally conditioned on accumulated
evidence). The one structural payoff: ensemble constants (review-panel
sizes, vote thresholds, retry budgets) are statistical parameters that
become derivable once golden-instance calibration sets exist (T-191 Phase 3
+ a conformal successor). Until then: spend tokens on conditioning, not on
draws.

**Standing guardrail (already ratified in the disambiguation arc):** all
these lenses are narrative. No ambiguity, entropy, amplitude, overlap, or
temperature carriers. Coverage, residual, convergence, and provenance remain
the only truth surfaces.
