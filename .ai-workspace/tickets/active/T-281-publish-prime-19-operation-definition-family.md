## Target Truth

ABIogenesis exposes one installed Public operation family:

```text
admit common envelope
  -> select exact operation-and-definition-key contract
  -> call its concrete owner-local port
  -> project its exact result, refusal, or non-terminal outcome
```

Product owns Product meaning. Validator owns conformance evaluation. HoG
executes admitted GTL. ABG exclusively owns admitted runtime events and the
Event Calculus that derives runtime truth. Replay deterministically
reconstructs and projects that truth. Release operations remain concrete and
callable but refuse success until their later milestone authority exists.

The SDK, CLI, bounded Codex process shell, JSON Schemas, static public catalog,
Product manifest, and replay are generated or exact projections of this same
family. None owns a roster, semantic branch, runtime fact, catalog admission,
or compatibility path.

## Superseded Truth

This migration removes the legacy root Public workflow and every authority
relation that depends on it:

- `RootPublicInvocation`, `ROOT_PUBLIC_OPERATION_DEFINITIONS`,
  `ROOT_PUBLIC_OPERATION_IDS`, `parseRootPublicInvocation`, generic
  `PublicOutcome`, and old invocation schemas;
- `applyRootPublicInvocation` and operation-identity semantic dispatch in
  Public;
- `RootOperationState`, the context-keyed `rootOperationStates` WeakMap, its
  prior-invocation maps, and the duplicate-invocation Set;
- `pendingReopenAuthority` and implicit remembered-prefix reopening;
- verified/resolved/install/catalog/application/source-result authority
  represented only by a WeakMap, WeakSet, object brand, retained context, or
  process-local registry;
- `legacyRequest`, `indexedRequest ?? legacyRequest`, new-to-old translation,
  compatibility facades, and dual-family exports;
- Public-owned semantic catalogs or rival ABG runtime catalog admission;
- raw-event scans or global-tail currentness that compete with the scoped
  Event Calculus; and
- legacy-semantic tests that require those carriers or authority paths.

The replacement may not hide any listed relation behind a renamed registry,
interface, metadata string, helper, or adapter.

## Authority Relations Requiring Gate 1 Disposition

### Explicit carriers and prefix

Verification and resolution return complete canonical immutable carriers.
Downstream operations accept those carriers explicitly and revalidate them
against the identified Product bytes and admitted durable prefix where
admission is required. Parsing arbitrary input yields only a candidate.
ABG-backed rehydration yields an admitted projection or continuation basis.
No public constructor can mint admission or provenance.

Every effectful request identifies the durable prefix it consumes. Invocation
uniqueness comes from admitted event truth. Read-only repeatability is an
explicit definition property, never a bypass around a volatile Set.

The common admitted-envelope refusal family contains exactly
`duplicate_invocation`, `invalid_request`, `missing_prerequisite`,
`owner_refusal`, and `target_mismatch`. `owner_refusal` is the common slot for
an exact typed owner-local refusal; it may not collapse that refusal into an
untyped JSON object or arbitrary string. SDK, CLI, schemas, and replay preserve
the same outer code and exact nested owner refusal.

### Static and runtime catalogs

PFC-F08 is the static publication relation:

```text
exact publication attempt
  -> static PublicContractCatalog
  | exact PFC-F08 refusal
```

It emits no runtime event. ABG separately admits runtime Product catalog events
and the Event Calculus derives admitted runtime catalog truth. Product and
Public may neither aggregate nor admit a rival runtime catalog.

Successful PFC-F08 preserves every retained row byte-for-byte and replaces
exactly the three common plus eighteen operation identities. Its eight failure
classes are `forbidden_operation_identity`, `duplicate_contract_identity`,
`missing_projected_identity`, `unexpected_projected_identity`,
`retained_row_changed`, `owning_product_mismatch`, `unresolved_locator`, and
`content_digest_mismatch`. Each failed attempt produces one exact refusal with
unique non-empty issue paths, no output catalog or diagnostic, and no runtime
event.

### Deterministic CatalogApplication

`catalog.view` is an eventless deterministic narrowing of an admitted runtime
catalog by an exact allowlist.

`CatalogApplication` is not an admission. It is a complete canonical total
function of:

```text
admitted immutable install
+ deterministic catalog view
+ exact declaration
+ explicit durable prefix
```

An independently reconstructed equal carrier must be accepted without its
originating object, store, brand, constructor capability, or retained context.
Construction emits no event and changes no runtime truth. `run.invoke`
revalidates it, and the invocation event records its exact use.

### Runtime Event Calculus

ABG owns scope-keyed artifact fluents, same-scope collision refusal,
ordinal-ordered projection, latest-applicable-event selection within declared
run/frame/aggregate scope, full prior-attempt retry frontier and executable
input, invocation identity,
continuation, result, and closure. Unrelated valid events in another scope do
not change those truths. Replay and reads consume the same projection; raw
event scans cannot override it.

### Program identity and validation

Validator and HoG consume one normalized Program. Gate 1 must bind exact law
for unique node identity, non-empty start and terminal sets, terminal
outdegree, declared non-terminal outdegree, reachability, boundedness, and
declared recursion. Invalid topology refuses before any leaf effect. Canonical
GraphFunction semantic membership uses explicit code-unit ordering, not
locale-sensitive identity ordering.
