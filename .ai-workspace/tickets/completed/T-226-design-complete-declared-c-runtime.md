## Target Truth

The runtime consumes the compiled `workflow.C` carrier directly. Each selected
`(program, role, fibre, arm)` names one declared stage interior through the
existing traversal algebra; it is not vector-specific routing. All seven C terms,
the one uniform C-call envelope over every 5.0-reachable arm,
current hook attachment scopes, result instruction/admission/materialization,
standard F_D assessment, consequence/re-entry projection, ordinal replay,
store-scoped emission, singular continuation export, typed basis-fork outcome,
and bounded conformance-enforcement gate have explicit owners and interfaces.
