# Deployed Domain — document_to_requirements

This directory ships the `document_to_requirements` deployed ODD/GTL/ABG
domain that `odd_chat` loads as its default proof domain after the T-131
sandbox build.

Authority: `domain.json` in this directory. It re-publishes the same
`defaultDomain` block declared in `../../bootstrap.md`'s scenario contract
(`t131.guided_odd_chat.bootstrap.v1`). The bootstrap remains the single
scenario source of truth; this package is the addressable, loadable form
of that domain that `odd_chat workspace create … domain.json` and
`odd_chat graph-functions …` consume at runtime.

Contents:

- `domain.json` — graph nodes, vectors, lawful actions, graph functions,
  carrier schemas, and non-closure conditions for the domain.

Lifecycle:

- The fixture provides this package as static input.
- The T-131 live build copies it into the sandbox alongside the built
  `odd_chat` CLI.
- The CLI's smoke test commands load this exact `domain.json`.
- The domain itself is not generated by `odd_chat` and not generated by
  `odd_sdlc`. It is authoring data that `odd_chat` operates over.

Adding a sibling deployed domain follows the same shape: a directory under
`domains/<name>/` containing one `domain.json` declaring graph topology,
graph functions, lawful actions, and carrier schemas.
