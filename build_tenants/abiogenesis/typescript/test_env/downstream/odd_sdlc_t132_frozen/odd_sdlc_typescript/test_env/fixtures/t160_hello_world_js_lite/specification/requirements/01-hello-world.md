# Hello-World Requirements

**Status**: Active
**Derived From**: `T-160 lite fixture`

## REQ-T160-001

The product shall provide one JavaScript executable source file at
`build_tenants/hello_world_javascript/src/hello.js`.

## REQ-T160-002

Running `node build_tenants/hello_world_javascript/src/hello.js` shall write
exactly `Hello, world!` to standard output after trimming trailing whitespace.
