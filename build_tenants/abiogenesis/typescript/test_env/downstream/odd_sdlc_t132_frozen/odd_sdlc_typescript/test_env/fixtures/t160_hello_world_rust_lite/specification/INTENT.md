# Intent

**Status**: Active
**Derived From**: `T-160 Rust lite fixture`

`t160_hello_world_rust_lite` exists to prove that the lite traversal overlay can
start from conformed project authority, skip the full SDLC graph, and
materialize one executable Rust product tenant.

The builder substrate is installed `odd_sdlc`; the generated product itself has
no runtime dependency on `odd_sdlc`.
