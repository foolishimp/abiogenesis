# Product

**Status**: Active
**Derived From**: `T-174 live fixture`

`t174_parallel_hello_world_js` is a single-tenant JavaScript hello-world
product built under `build_tenants/parallel_hello_world`.

## Product Files

- `package.json` declares a Node.js module package.
- `src/hello.js` exports the hello branch.
- `src/world.js` exports the world branch.
- `src/index.js` composes the public `helloWorld` behavior.
- `test/hello.test.js` verifies the hello branch.
- `test/world.test.js` verifies the world branch.

These files are generated by traversal and must not be present in the fixture.

```text

```
