## Design Position

The TypeScript tenant target is:

```text
SDLC(ABG(Iterate(SDLC.Graph, ioc(SDLC hooks))))
```

GTL publishes the graph-function programs.

ABG owns traversal, frames, continuation, events, projection, lineage, and
provenance.

`odd_sdlc.TS` owns SDLC domain assets, graph functions, hook contracts,
workspace admission, public target meaning, gap triage, requirement closure,
traceability, operational evidence, and product projections.

The Python tenant remains discovery evidence. Its current behavior informs this
design, but its module layout and imperative controller shape are not target
architecture.
