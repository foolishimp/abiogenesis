## Source authentication and refusal

The native projector must establish all of the following from the actual
durable history and archived bytes, before any C0 effect:

1. The selected prefix is an authentic ancestor of the current store. Its
   source CCall, attempt, actor, process, original Program/GF/materialization,
   implementation/install and transport binding resolve uniquely. Reconstruct
   the original admitted task and Worker request, including exact prompt and
   response schema; their digests must equal the recorded dispatch. Preserve
   the actual failed result and judgment as historical facts.
2. Read only the archive loci derived from that binding. Check every required
   artifact length/digest against native artifact observation. Reconstruct
   stdout from admitted chunk boundaries and digests in stream order, with
   all proposal and acknowledgment bytes observed before exit. Missing chunks,
   gaps, foreign events, conflicting payloads, late/descendant-only bytes or
   absent provenance refuse. Caller paths, transcript timestamps and the
   first-cause index are locators, never authentication substitutes.
3. Select exactly one complete protocol StructuredOutput tool-use object and
   its subsequent successful matching acknowledgment, in the same session and
   attempt, under the original schema-enabled closed lane. Require the actual
   original dispatch's no-ordinary-tools boundary. Multiple proposals,
   contradictory acknowledgments/results, protocol error, missing match or
   unauthorized tools refuse. Only complete, unambiguous protocol JSON records
   participate; reject duplicate-key ambiguity. Retain an incomplete trailing
   record as failure evidence without parsing, repairing or using it.
4. Apply the existing raw Worker-result constructor against the original task:
   exact keys/cardinality/order/target refs, Unicode scalar validity and
   text/base64 XOR, canonical binary identity, and no normalization. The
   acknowledgment proves protocol receipt only; the authenticated proposal
   supplies bytes, and native checks alone establish artifact eligibility.

This first contract covers the observed terminated, status-zero, `no_output`
case. Other failure classes retain their existing behavior; broader salvage
requires its own source-complete relation. No claim is made about the cause of
the original truncation or proof of model-internal intent.

The new occurrence has its own admitted execution basis, current binding,
invocation grant, CCall and judgments. The old grant grants no new effect.
Require the current task to equal its genuine admitted native bridge/selection
projection. In the changed-binding D1 path, both the original and current

path, kind, file identity and bytes or exact absence, roles, dependencies,

Reject missing/extra/ambiguous targets, changed preimages, a different workspace,
broader effects or altered construction instructions. Only derived current
coordinates may differ. Map original proposal target refs to current refs by
that authenticated bijection, preserving replacement bytes exactly; never join
historical/current vectors merely by incidental array position. Regenerate
the current bundle with the existing C1 constructor.

Observe physical currentness at the new bridge/recovery boundary before C0;
C0 retains its own currentness and authority checks. After C0, replay and result
admission use saved admitted observations and producer joins, not a demand that
old bytes remain on disk. Actual returned dependency bytes must still be
checked for preservation. The recovered proposal does not enforce no-ops before
C0, and does not authorize a reset if effects or tests subsequently fail.
