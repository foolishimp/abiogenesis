# Product Requirement Families

This domain owns catalog-product, installation, public operator policy,
product self-conformance, qualification, and scenario obligations.

Use these families for the observable product contract that sits above pure language and engine law.

## Scope

- policy and operational governance
- addressable public contract, schema, vocabulary, corpus, operation, and capability catalogs
- catalog-product descriptors, contributions, dependencies, and public reads
- the SYSTEM-owned agent-invocable Consensus GraphFunction
- installed substrate contracts
- ABIogenesis product self-conformance
- qualification and evidence expectations
- end-to-end scenario obligations

ABIogenesis 5.0 retains self-conformance and qualification but excludes the
planned 5.1 observer/tuner Product (`A5-F12`, `ABG5-S04`) and its public
operation variants. Exact release applicability is defined by
[`../README.md`](../README.md).
